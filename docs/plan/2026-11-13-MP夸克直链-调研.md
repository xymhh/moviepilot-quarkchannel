# MP 夸克直链频道 — 调研（2026-11-13）

## 目标
用 **MoviePilot v3.2.6 原生流程与 UI** 跑一条「网盘分享链接 → 下载到本地」的管线：
订阅 / 搜索 / 下载管理 / 下载历史 / 整理 / 刮削 / STRM / Emby / 通知 全部由 MP 提供，
插件只补 MP 缺的两块：**网盘分享型资源源** 与 **非种子下载执行**。

约束（用户明确）：不使用 CloudSubscribeX 插件。

## 关键源码事实（已核实）

1. `app/chain/base.py:665 search_plugin_torrents()` — 以 `site={}` 调用插件 `search_torrents`，
   **不需要建站点**即可把插件当资源源并入每次搜索（契约 `media-discovery / ORDERED_LIST_MERGE`）。
2. `app/runtime/extensions/module/dispatcher.py:238` — 插件 provider **先于**系统模块执行，
   且 `plugin_short_circuit=True`（`contracts.py:125`）：插件返回非空且非 list 即短路系统下载器。
3. `app/application/torrent/download.py:474` — `download_torrent()` 只对 `magnet:` 透传，
   其余 URL 一律按 .torrent 二进制拉取并解析；解析失败 → "无法获取下载地址"，插件 `download` 轮不到。
4. `app/chain/download/batch.py:210` — 剧集订阅必须先拿到**种子文件清单**定集数（`_read_torrent`），
   磁力链（str content）直接返回 None → 整季/拆包/分包三个阶段全部放弃候选。
5. `app/application/torrent/download.py:568` — 目录名 = `torrent.name`，文件清单 = `files[].name`；
   即**合成种子可完全控制 MP 眼中的文件名与集数**。
6. `app/schemas/types.py:684` — `DownloaderType` 仅 Qbittorrent/Transmission/Rtorrent，
   插件无法在 UI 里新增下载器类型；`StorageSchema`(`:758`) 无 quark，仅 local/alipan/u115/rclone/alist/alistgo/smb。

## 结论

- 必须自研：一个纯 MP 插件，挂 3 类钩子（资源源 / 合成种子 / 下载执行）。
- 借鉴不复用：分享取链的接口链照 `gopeed-extension-quark`（`sharepage/token` → `sharepage/detail` → `file/download`，PC 客户端 UA）。
- 明确不做：改 MP 内核、加 `DownloaderType`、把夸克挂成 MP storage（后者只能经 alist/rclone）。
